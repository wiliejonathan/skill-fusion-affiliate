# Skill Fusion Affiliate Marketplace

Marketplace-style technology discovery website for **Skill Fusion**.

## MVP scope

- Responsive marketplace catalog
- Search and category filters
- Brand filtering
- Min/max price range
- Marketplace rating filter
- Skill Fusion Score filter
- Sorting by recommendation, score, trend, rating and price
- Wishlist and product comparison state
- Demo catalog clearly separated from future live affiliate data

## Roadmap

1. Official affiliate feed/API ingestion
2. Product normalization and deduplication
3. Category/specification mapping
4. Quality gate
5. Skill Fusion scoring engine
6. AUTO + APPROVAL publishing
7. Product detail pages
8. Affiliate deeplinks
9. Analytics: impression -> click -> affiliate click -> conversion -> EPC
10. SEO schema, sitemap and index controls
11. Admin dashboard

The long-term optimization target is **revenue per visitor**, not raw catalog size.
