# Blibli Affiliate setup for Skill Fusion

## Owner steps

1. Open the Blibli mobile app.
2. Go to Account -> Komisi Affiliate.
3. Register / complete Affiliate verification.
4. Prepare KTP and a personal Indonesian bank account for payout verification.
5. Register the Skill Fusion website as an Affiliate Media once the public site URL is available and the account flow allows it.
6. Confirm product-link sharing from the Affiliate page / product detail page.
7. Do not use self-purchases, related-party purchases, dropship transactions, abnormal bulk transactions, or excluded products to generate commissions.

## Product eligibility rules reflected in Skill Fusion

- Ready stock only
- Blibli Affiliate eligible products only
- Indonesia / IDR commerce
- Technology categories only
- Exclude digital products and other Blibli Affiliate exclusions
- Respect the 7-day attribution window and last-click attribution described by Blibli

## Integration status

Blibli's public Affiliate help pages document product affiliate links and web/private-site promotion, but no public Affiliate API/Data Feed is assumed by this project.

Therefore the catalog adapter starts in MANUAL / VERIFIED IMPORT mode. If the Blibli account exposes an official bulk source, export, feed or API, the adapter can be upgraded to AUTO + APPROVAL without changing the rest of the application.
